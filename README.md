# PySide6-compact-documentation
[This PySide6 documentation](https://natuurkundepracticumamsterdam.github.io/PySide6-compact-documentation/) is compact, focused on beginners, and while not complete, it is clear and explanatory.


# For developers

To compile and read this documentation locally during development, you can use `uv`:
```
uv run mkdocs serve
```
`uv` will take care of creating a virtual environment with the requirements.

To publish the documentation to GitHub:
```
uv run mkdocs gh-deploy
```
